# এমার্টক্স (Emertxe) মডিউল-ভিত্তিক বইয়ের তালিকা (Module-wise Book List)

এই তালিকায় এমার্টক্স এমবেডেড সিস্টেম কোর্সের প্রতিটি মডিউলের জন্য সেরা ইংরেজি এবং বাংলা বইগুলোর নাম দেওয়া হয়েছে।

---

## মডিউল ০১: লিনাক্স সিস্টেম (Linux Systems & Shell Scripting)

### English Books
- **The Linux Command Line** by William Shotts
- **Linux Command Line and Shell Scripting Bible** by Richard Blum
- **Wicked Cool Shell Scripts** by Dave Taylor

### Bangla Books
- **লিনাক্স ব্যবহারের হাতেখড়ি** - দ্বিমিক প্রকাশনী (Dimik Publication)
- **লিনাক্স টার্মিনাল এবং কমান্ড লাইন** - স্টাডি উইথ আনিস (Online/E-book)

---

## মডিউল ০২: অ্যাডভান্সড সি প্রোগ্রামিং (Advanced C / Embedded C)

- **The C Programming Language** by Kernighan and Ritchie (K&R)
- **Effective C** by Robert C. Seacord
- **Embedded C** by Pont Michael J

### Bangla Books
- **প্রোগ্রামিংয়ের বলদ টু বস (সি প্রোগ্রামিং)** - ঝংকার মাহবুব (Jhankar Mahbub)
- **কম্পিউটার প্রোগ্রামিং (১ম খণ্ড)** - তামিম শাহরিয়ার সুবিন (Tamim Shahriar Subeen)

## মডিউল ০৩: ডেটা স্ট্রাকচার এবং অ্যালগরিদম (Data Structures & Algorithms)

### Bangla Books

- **প্রোগ্রামিং কন্টেস্ট: ডেটা স্ট্রাকচার ও অ্যালগরিদম** - মোঃ মাহবুবুল হাসান (শান্ত)
